为什么选择 MareoWhy Mareo

免配置即用Works out of the box

无需注册模型服务、无需填写任何 API Key。登录你的账号，打开就能开始工作。 No model-service signup, no API keys to paste. Sign in and start working.

密钥不落地Keys never touch your machine

底层模型凭据托管在服务端，你的电脑上只保存登录令牌，密钥无法被读取或泄露。 Model credentials live server-side; your device only holds a login token that cannot be extracted into a usable key.

原生本地体验Native and local-first

原生 macOS 应用，DSH 运行时在你本机运行，会话记录与工作文件默认留在你的电脑。 A native macOS app running the DSH runtime locally; sessions and files stay on your machine.

干净的架构Clean architecture

Mareo 只是 DeepSeek Harness 的桌面壳，不修改其运行时，可随官方版本安全升级。 Mareo is a thin desktop shell over DeepSeek Harness — no forks, safe upgrades.

它是如何工作的How it works

  1. 安装 Mareo 并登录你的账号 Install Mareo and sign in with your account
  2. 模型请求经你的账号安全代理到 DeepSeek，密钥始终留在服务端 Model requests are proxied through your account; keys never leave the server
  3. 对话、文件与任务在你本机的 Harness 运行时中执行 Conversations, files and tasks run in the Harness runtime on your machine

常见问题FAQ

需要 DeepSeek API Key 吗？Do I need a DeepSeek API key?

不需要。登录你的账号即可使用，底层模型调用由服务端代理完成。 No. Sign in with your account and start; model calls are handled server-side.

怎么获得账号？How do I get an account?

内测期间向运营者领取访问令牌，在 Mareo 登录页粘贴即可。 During beta, request an access token from the operator and paste it into Mareo's sign-in screen.

支持哪些系统？Which systems are supported?

目前是 macOS Apple Silicon（arm64）内测版；其他平台后续规划。 Currently macOS on Apple Silicon (arm64) in beta; more platforms are planned.

我的对话数据在哪里？Where is my conversation data?

会话记录默认保存在你本机的 Mareo 数据目录；模型请求内容经网关转发处理。 Sessions are stored locally in Mareo's data directory; requests are forwarded through the gateway.

Mareo 与 DeepSeek Harness 是什么关系？How does Mareo relate to DeepSeek Harness?

Mareo 是 Harness 的桌面宿主，不改动其运行时，并遵循官方品牌指引署名「Built on DeepSeek Harness」。 Mareo is a desktop host for Harness. It never patches the runtime and credits "Built on DeepSeek Harness" per official guidelines.
