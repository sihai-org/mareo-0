# Mareo 隐私说明

本说明对应官网 <https://mareo.cn/privacy.html>。最后更新：2026-09-12。

## 我们收集什么

为了知道 Mareo **能否正常安装、启动、登录**，客户端会上报以下几类**匿名统计事件**：

| 事件 | 触发时机 | 携带内容 |
|---|---|---|
| `install_confirmed` | 首次安装后成功启动并登录 | 版本号、操作系统、CPU 架构 |
| `launch` | 每次启动结束时 | 版本号、操作系统、成功与否、失败阶段（更新检查/登录/引擎）、耗时毫秒 |
| `harness_exit` | 内置引擎意外退出时 | 版本号、操作系统、已运行时长、退出码/信号，以及**崩溃前最后 20 行技术输出**（最多 4KB；已去除本机路径、用户名与启动令牌） |
| `signin` | 登录流程结束时 | 版本号、操作系统、结果（成功 / 验证码错误 / 发信失败 / 超时 / 取消） |

**不收集**：对话内容、提示词、模型回复、附件、邮箱地址、昵称、访问令牌、IP 地址（服务端不落库）、设备指纹（无任何持久化设备标识）。

说明：

- 登录成功前客户端没有账号凭据，此时的登录失败事件是**匿名**的（无法关联到具体账号），否则我们无法发现"装上了但登不进去"这类故障。
- 服务端会为限流而**在内存中短暂**处理请求来源 IP，不写入数据库、不用于任何其他用途。
- 错误描述在发送前会**去掉本机绝对路径**（因此不会带上你的用户名），并去掉启动令牌。
- 崩溃报告里的技术输出用于定位"引擎为什么会崩"，它取自引擎自己的错误输出，**不包含你的对话记录**；同样受下面的开关控制，关掉统计即不再上报。

## 用来做什么

- 统计安装成功率、首次启动稳定性、登录与模型调用稳定性、引擎异常退出率
- 发现并修复故障

不用于广告、不用于用户画像、不向任何第三方出售或共享（模型请求本身经 Mareo 网关转发至 DeepSeek，见下）。

## 模型请求

聊天内容由客户端发起、经 Mareo 网关转发到 DeepSeek 完成推理。网关会记录每次请求的**用量元数据**（账号、模型名、字符数、耗时、HTTP 状态码），用于配额与故障排查，**不记录对话内容**。

## 你的选择

- **设置 → 账户 → 发送匿名使用统计**：关闭后客户端立即停止上报，本地队列一并清空。
- 关闭统计不影响 Mareo 的任何功能。
- 需要删除已经上报的数据？发邮件到 `contact@mareo.ai` 说明你的账号，我们会删除该账号关联的全部事件记录。

## 数据存放与保留

事件与用量数据存放在 Mareo 自有的阿里云服务器（中国杭州），保留期限为 **180 天**，到期后自动清理。

## 变更

本说明如有变更，会在官网与本页更新，并标注更新日期。

## 官网访问统计

官网（mareo.cn）上有一个**只计数**的浏览统计：页面加载时由网页向 Mareo 网关发送一次"这一页被打开了"。它：

- 只累计**按天、按页面**的浏览次数（例如 `2026-09-14 / 12 次`），**不保存每一次访问的记录**；
- **不存 IP、不存 User-Agent、不写 Cookie、不使用任何设备或用户标识符**；
- 不执行 JavaScript 的环境（绝大多数爬虫与扫描器）不会被计入；
- 服务端仅为防刷而**在内存中短暂**处理来源 IP，与上文客户端统计一致。

因此我们能看到"官网每天大约有多少真人浏览、看了哪些页面"，但无法、也不会回答"某个具体的人访问过官网"。
